# Scientific Scope and Limitations

## What this project can claim

- It uses the official MaleCNS v1.0 connectome as a structural constraint.
- Traced neurons and their retained connections remain traceable to official body IDs.
- Functional labels summarize annotated cell classes and established circuit associations.
- Future activity displays can show the state of a declared computational model.
- Interventions can test consequences within that model.

## What it cannot currently claim

- An exact emulation of a living fly
- Recovery of the imaged fly's memories or internal state
- Biological synaptic efficacy from synapse count alone
- Human-like happiness, pain, intention, or consciousness
- Naturally emergent behavior when an engineered controller or adapter supplies it
- Validation merely because an animation looks plausible

## “Happiness” and reward language

For public explanations, use terms such as positive valence, appetitive reinforcement, attraction, learned value, reward prediction, or approach bias when supported. A dopaminergic or mushroom-body signal is not direct evidence of a subjective emotional experience. The interface uses “Learning & reward” as an accessible circuit label and provides this qualification nearby.

## Four evidence classes

Every scientific statement or visual state should be classed as one of:

1. **Dataset fact** — directly present in MaleCNS anatomy or annotations.
2. **Literature interpretation** — supported by cited experimental research.
3. **Model assumption** — equation, parameter, sign inference, initial condition, or plasticity rule chosen by the project.
4. **Simulation result** — output produced under a declared model and experiment configuration.

These classes should remain visually and programmatically distinct.

## Validation standard

A compelling demo is not scientific validation. Validation should include structural checks, held-out stimulus responses, behavior measurements, causal activation/silencing comparisons, parameter sensitivity, multiple random seeds, and explicit failure cases.
